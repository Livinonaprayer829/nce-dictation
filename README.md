# NCE 点读站（含默写模式）

基于 [iChochy/NCE](https://github.com/iChochy/NCE)（MIT 协议）的纯静态新概念英语点读站，额外实现了**默写练习**。

**在线使用**：https://livinonaprayer829.github.io/nce-dictation/

手机浏览器打开后「添加到主屏幕」，即可当 App 使用（全屏、无地址栏）。

## 默写模式

- **每句一个播放钮**：按 LRC 时间轴只播这一句，到句尾自动暂停，不复用整课播放
- **逐句输入**：Enter 跳到下一句，Ctrl+Enter 只检查当前句
- **逐词比对**：漏掉的词标红加下划线，多打的词标绿删除线；整句没写时只平铺原文，避免满屏标红
- **行级重写**：检查后每行出现 ↺，点它只清空这一句；顶部「全部重写」清空整课
- **草稿自存**：答案自动写入浏览器 `localStorage`，切换课次或刷新都不丢
- **统计**：全查完显示「正确 x / 总句数」，只查了几行显示「正确 x / 已查 y」

## 使用

直接访问线上地址，无需安装、无需后端。

## 本地开发

纯静态项目，没有构建步骤：

```bash
python -m http.server 8081
```

浏览器打开 <http://localhost:8081>。

## 发布

仓库根目录即网站根目录（`main` 分支，含 `.nojekyll`），推送到 `main` 后 GitHub Pages 会自动构建，约 30–60 秒生效。
